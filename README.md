# Hello Jinho!

브라우저 시작 페이지용 세계시간과 환율. 정적 HTML 두 장, 빌드 도구도 외부 라이브러리도 API 키도 없습니다.

| 페이지 | 내용 |
|---|---|
| `index.html` | 기준 도시의 큰 시계, 도시별 시각·시차·날씨·낮/밤 막대, −24 ~ +24시간 시간 이동 |
| `exchange.html` | 통화 변환기, 원화 기준 환율, 최근 30일 추이 |

공용 파일은 `meridian.css` (디자인 토큰) 와 `meridian.js` (도시 표·시간 계산·아이콘) 입니다.

날씨는 별도 페이지가 아니라 시작 페이지의 도시 목록 안에 들어 있습니다. 각 도시 줄에 아이콘·기온·날씨 상태가 함께 나옵니다.

## 데이터

- 날씨: [Open-Meteo](https://open-meteo.com/) — 도시 전체를 한 번의 요청으로 받습니다
- 환율: [exchangerate-api](https://www.exchangerate-api.com) — 주말 포함 매일 갱신. 30일 추이는 과거 데이터가 있는 [Frankfurter](https://frankfurter.dev/)(ECB)

둘 다 키가 필요 없습니다. 일출·일몰은 도시 좌표로 직접 계산합니다.

현재 환율은 exchangerate-api 를 씁니다. ECB 는 영업일에만 고시해 월요일 아침에 금요일 값이 그대로 나오기 때문입니다. 과거 30일치는 ECB 만 제공하므로 그래프는 ECB 를 씁니다.

어느 쪽이든 원화 환산은 교차환율로 계산합니다. `base=KRW` 로 받으면 유효숫자가 두 자리로 잘려(USD 가 `0.00072`) 값이 어긋나므로 그렇게 두면 안 됩니다.

한국 은행 고시환율(하나은행 등)은 공개 API 가 없고 네이버 금융은 브라우저 요청을 403 으로 막습니다. 서버 없이 정적 페이지로는 가져올 수 없습니다.

## 도시 목록 바꾸기

목록은 **주소 → 브라우저 저장본 → 소스 기본값** 순으로 우선합니다.

### 이 기기에서만

페이지에서 직접 추가·삭제하면 됩니다. 그 브라우저에만 남습니다.

### 링크로 공유

`주소 복사` 를 누르면 현재 목록이 담긴 주소가 복사됩니다.

```
https://<사용자>.github.io/<저장소>/?c=서울,런던,뉴욕
```

이 주소로 열면 그 목록이 뜨고 그 기기에 저장까지 됩니다. 환율 페이지는 `?v=USD,EUR,JPY` 를 씁니다.

### 모든 기기에

`meridian.js` 의 `DEFAULT_CITIES` 와 `DEFAULT_CURRENCIES` 를 고치고 커밋합니다. GitHub Pages 가 자동 배포합니다.

## 도시 추가

`meridian.js` 의 `CITIES` 에 `'도시명': ['IANA/타임존', 위도, 경도, '국가']` 를 넣습니다. 날씨와 일출·일몰이 좌표에서 함께 계산되므로 한 줄이면 끝납니다.

## 브라우저 시작 페이지로 쓰기

크롬 `설정 → 시작 그룹 → 특정 페이지 또는 페이지 모음 열기` 에 배포 주소를 넣습니다.

## 디자인

`DESIGN.md` (Linear 계열 다크 시스템) 를 기준으로 만들었습니다. 캔버스 `#010102`, 단일 액센트 `#5e6ad2`, 4단 서피스, Inter / JetBrains Mono / IBM Plex Sans KR. 다크 단일 테마이며 밝은 테마는 두지 않습니다.

파일명과 `localStorage` 키는 이전 이름인 `meridian` 을 그대로 씁니다. 저장 키를 바꾸면 이미 저장된 도시·통화 목록이 초기화되기 때문입니다.
