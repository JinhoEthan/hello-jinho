# 세계시간

브라우저 시작 페이지용 세계시계. 단일 HTML 파일, 외부 라이브러리 없음.

- 기준 도시의 현재 시각 · 날짜 · 날씨
- 도시별 시각과 시차, 낮/밤 표시
- −24 ~ +24시간 시간 이동 슬라이더
- 다크모드 자동 대응

날씨는 [Open-Meteo](https://open-meteo.com/)를 씁니다. API 키가 필요 없습니다.

## 도시 목록 바꾸기

목록은 세 곳에서 정해지며 **주소 → 브라우저 저장본 → 소스 기본값** 순으로 우선합니다.

### 이 기기에서만

페이지에서 직접 추가·삭제하면 됩니다. 그 브라우저에만 남습니다.

### 모든 기기에

1. 페이지에서 목록을 원하는 대로 맞춥니다
2. **`기본값 복사`** 를 누릅니다 — 클립보드에 이런 한 줄이 들어갑니다

   ```js
   const DEFAULTS=["서울","방콕","두바이","런던","뉴욕","로스앤젤레스"];
   ```

3. `index.html` 에서 `const DEFAULTS=` 로 시작하는 줄을 그것으로 교체하고 커밋합니다
4. GitHub Pages 가 자동 배포합니다

GitHub 웹 에디터(저장소에서 `index.html` → 연필 아이콘)에서 바로 고쳐도 됩니다. PC에 파일이 없어도 됩니다.

### 링크로 공유

**`주소 복사`** 를 누르면 현재 목록이 담긴 주소가 복사됩니다.

```
https://<사용자>.github.io/<저장소>/?c=서울,런던,뉴욕
```

이 주소로 열면 그 목록이 뜨고 그 기기에 저장까지 됩니다.

## 도시 추가

`index.html` 의 `CITIES` 배열에 `["도시명","IANA/타임존"]` 을 넣습니다. 헤더 날씨까지 나오게 하려면 `COORDS` 에 `"도시명":[위도,경도]` 도 함께 넣습니다.

## 브라우저 시작 페이지로 쓰기

크롬 `설정 → 시작 그룹 → 특정 페이지 또는 페이지 모음 열기` 에 배포 주소를 넣습니다.
